# Code of Conduct

BLCVoice is intended to be a professional, technically focused open-source project.

## Expected behavior

- Be respectful and specific when discussing code, design, bugs, and trade-offs.
- Critique ideas and implementations rather than people.
- Provide reproducible evidence for technical claims when possible.
- Respect maintainer decisions about scope, architecture, security, and release policy.
- Keep issues and pull requests relevant to the project.

## Unacceptable behavior

Harassment, threats, discriminatory attacks, personal insults, deliberate disruption, spam, or publishing another person's private information are not acceptable.

## Enforcement

The maintainer may edit, hide, lock, or remove content and may restrict participation when necessary to protect the project and its contributors. Severe or repeated violations may result in a permanent ban from project spaces.

## Reporting

For conduct concerns that should not be discussed publicly, contact the maintainer through an appropriate private GitHub channel. Security vulnerabilities must instead follow `SECURITY.md`.
