# Support

BLCVoice is maintained as an open-source project. Please use the appropriate channel so maintenance work remains actionable.

## Bugs

Open a GitHub issue using the bug report template. Include your operating system, BLCVoice version or commit, reproduction steps, expected behavior, actual behavior, and relevant logs.

## Feature requests

Use the feature request template and describe the user problem before proposing an implementation.

## Security issues

Do not disclose suspected vulnerabilities in a public issue. Follow the process in `SECURITY.md`.

## General usage questions

Before opening an issue, check the README, project documentation, existing issues, and closed issues. Issues that cannot be reproduced or do not contain enough information may be closed until additional evidence is available.

## Maintenance policy

The maintainer prioritizes security, regressions, data loss, crashes, core dictation reliability, and changes that improve the project for a broad set of users. Opening an issue does not guarantee that a feature will be implemented.
